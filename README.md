# Frontier Defense

An original, touch-first tower defense game built as an installable Progressive Web App. It captures the strategic feel of classic path-based tower defense without using Fieldrunners 2 code, assets, names, audio, or level designs.

## Play on Android
1. Enable GitHub Pages: repository **Settings → Pages → Deploy from a branch → main / root**.
2. Open the published Pages URL in Chrome on Android.
3. Use Chrome **⋮ → Add to Home screen** to install.

## Gameplay
- 20 escalating waves, with elite units every fifth wave.
- Four defense systems: Ranger, Blaster, Frost and Rail.
- Tap a tile to deploy; tap a deployed tower to inspect it.
- Upgrade towers to level 3 or sell them for supplies.
- Pause, 2× speed, sound effects and touch controls.
- The enemy route cannot be blocked; offline caching after first load.

## About Craft Anything
The requested Craft Anything fork is an AI-assisted reverse-engineering/rebuild workbench, not a browser game engine or web-game starter. Its repository documentation identifies it as a pure-Rust desktop/CLI/MCP application. This game is a clean, separate web implementation; no Craft Anything code was copied into this repository.
